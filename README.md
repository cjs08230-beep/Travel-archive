# ✈︎ 내 여행 기록

방문한 나라와 도시를 아카이빙하는 PWA 앱

## Vercel 배포 방법

1. [github.com](https://github.com) 가입 후 새 repository 만들기
2. 이 폴더 파일들을 전부 올리기
3. [vercel.com](https://vercel.com) 에서 GitHub 연결 후 배포
4. 생성된 URL을 폰에서 열고 홈 화면에 추가

## 폰에 설치하기

- **아이폰**: Safari → 공유버튼 → "홈 화면에 추가"
- **안드로이드**: Chrome → 메뉴(⋮) → "앱 설치"
